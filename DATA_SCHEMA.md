# World Data Schema Reference

This document provides a detailed reference for the `world.json` file generated by the World Generator. This standardized format is designed to be consumed by the **Invention Engine** game framework.

## 📂 Root Structure

| Field | Type | Description |
| :--- | :--- | :--- |
| `seed` | `string` | The alphanumeric seed used for reproducible generation. |
| `lore` | `object` \| `null` | AI-generated narrative data (only present if `--ai-key` is used). |
| `grid` | `object` | Low-level geographic data (spacing and heightmap). |
| `pack` | `object` | High-level world entities (states, burgs, cultures). |
| `metadata` | `object` | (Optional) Custom data added by plugins. |

---

## 🧠 Lore Object (`lore`)
Generated via Google Gemini AI.

| Field | Type | Description |
| :--- | :--- | :--- |
| `worldName` | `string` | The formal name of the generated world. |
| `creationMyth` | `string` | A concise narrative explaining the world's origin. |
| `era` | `string` | The current historical epoch name. |
| `cultures` | `Array<CultureLore>` | Narrative identity for each procedural culture. |
| `history` | `Array<HistoryEvent>` | A timeline of major world events. |

### CultureLore
- `name`: Matches the procedural name in `pack.cultures`.
- `description`: A 1-2 sentence overview of the people.
- `values`: List of 3 core societal beliefs.
- `traditions`: List of unique cultural practices.

---

## 🏙️ Pack Object (`pack`)
Procedural world data generated by the FMG engine.

### States (`pack.states`)
Represents political entities.
- `i`: Unique State ID.
- `name`: Name of the nation.
- `color`: Hex code for map rendering.
- `capital`: ID of the burg serving as the capital.
- `center`: Cell ID where the state originated.

### Burgs (`pack.burgs`)
Represents cities and settlements.
- `i`: Unique Burg ID.
- `name`: Name of the city.
- `cell`: The ID of the Voronoi cell where it is located.
- `state`: ID of the state it belongs to.
- `population`: Procedural population value.
- `capital`: Boolean, true if it's a state capital.

### Cultures (`pack.cultures`)
Geographic distribution of peoples.
- `i`: Unique Culture ID.
- `name`: Name of the linguistic/cultural group.
- `type`: Category (e.g., "Nomadic", "Highland", "River").
- `center`: Origin cell.

---

## 🌍 Grid Object (`grid`)
Raw spatial data.

| Field | Type | Description |
| :--- | :--- | :--- |
| `spacing` | `number` | The distance between Voronoi points. |
| `cells.h` | `Array<number>` | An array of elevation values (0-100) mapped to cell IDs. |

---

## 🔌 Example Data Flow
1. **Engine** calculates `grid.cells.h` (Mountains/Seas).
2. **Engine** places `pack.burgs` (Cities) based on water proximity.
3. **Gemini AI** reads the city/culture names and writes the `lore` bible.
4. **Plugins** add `metadata.timestamp`.
5. **Output** is saved as a single unified `world.json`.
